# Kampüs Etkinlikleri - Sprint 2

Bu proje Web Teknolojileri ve Programlama dersi Sprint 2 görevi için güncellenmiştir. Sprint 1'de oluşturulan HTML5 iskeletinin üzerine mobil öncelikli (mobile-first) CSS tasarımı eklenmiş, Grid (Izgara) yapısı kullanılmış ve renklendirmeler öğrenci numarasına göre (2416501013) özel CSS değişkenleriyle yapılmıştır.
